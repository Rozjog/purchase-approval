# Purchase Approval – система согласования закупок

## Назначение

Purchase Approval – консольное приложение для создания и согласования заявок на закупку.

Приложение позволяет:

* просматривать заявки;
* создавать заявки;
* находить заявки по названию;
* отменять заявки;
* просматривать сотрудников;
* добавлять новых сотрудников;
* создавать согласования;
* просматривать согласования;
* принимать решения по согласованиям;
* просматривать принятые решения;
* хранить данные между запусками приложения.

## Целевая аудитория

Сотрудники и руководители организации, которым необходимо создавать заявки на закупку и согласовывать их.

## Предметная область

Основными объектами предметной области являются:

* сотрудник;
* заявка;
* согласование;
* решение.

Сотрудник может создать заявку на закупку.

Для заявки может быть создано согласование, которое связано с сотрудником, принимающим решение.

Возможность согласования зависит от суммы заявки и роли сотрудника.

После принятия решения изменяется статус согласования и соответствующей заявки.

## Основные сущности

### Employee – сотрудник

Объект `Employee` представляет сотрудника системы.

Основные атрибуты:

* `id` – уникальный идентификатор сотрудника;
* `name` – имя сотрудника;
* `role` – роль сотрудника.

Основные методы:

* `__str__()` – строковое представление сотрудника.

### Request – заявка

Объект `Request` представляет заявку на закупку.

Основные атрибуты:

* `id` – уникальный идентификатор заявки;
* `name` – название заявки;
* `amount` – сумма заявки;
* `contractor` – контрагент;
* `employee` – объект `Employee`, создавший заявку;
* `status` – статус заявки.

Основные методы:

* `cancel()` – отмена заявки;
* `__str__()` – строковое представление заявки.

### Approval – согласование

Объект `Approval` представляет согласование заявки сотрудником.

Основные атрибуты:

* `id` – уникальный идентификатор согласования;
* `request` – объект `Request`;
* `employee` – объект `Employee`, выполняющий согласование;
* `status` – статус согласования.

Основные методы:

* `can_approve()` – проверка возможности сотрудника согласовать заявку;
* `__str__()` – строковое представление согласования.

### Decision – решение

Объект `Decision` представляет решение по согласованию.

Основные атрибуты:

* `id` – уникальный идентификатор решения;
* `approval` – объект `Approval`;
* `result` – результат решения;
* `comment` – комментарий к решению.

Основные методы:

* `apply()` – применение решения к согласованию и заявке;
* `__str__()` – строковое представление решения.

## Основные операции

### Работа с сотрудниками

* добавление сотрудника;
* поиск сотрудника по идентификатору;
* просмотр списка сотрудников.

### Работа с заявками

* создание заявки;
* поиск заявки по названию;
* отмена заявки;
* просмотр списка заявок.

### Работа с согласованиями

* создание согласования;
* поиск согласования по идентификатору;
* проверка возможности согласования;
* просмотр списка согласований.

### Работа с решениями

* создание решения;
* применение решения;
* поиск решения по идентификатору;
* просмотр списка решений.

При принятии решения проверяется роль согласующего сотрудника и доступный бюджет.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

* `data/employees.json`;
* `data/requests.json`;
* `data/approvals.json`;
* `data/decisions.json`.

При загрузке данные из JSON преобразуются в объекты `Employee`, `Request`, `Approval` и `Decision`.

При сохранении объекты преобразуются в данные JSON.

Для связи заявки с сотрудником в `requests.json` используется идентификатор `employee_id`.

Для связи согласования с заявкой и сотрудником в `approvals.json` используются идентификаторы `request_id` и `employee_id`.

Для связи решения с согласованием в `decisions.json` используется идентификатор `approval_id`.

## Назначение модулей

### `main.py`

Точка входа в приложение.

Отвечает за:

* запуск приложения;
* отображение меню;
* получение данных от пользователя;
* организацию пользовательских сценариев.

### `models/employees.py`

Содержит класс `Employee` и функции работы с сотрудниками.

### `models/requests.py`

Содержит класс `Request` и функции работы с заявками.

### `models/approvals.py`

Содержит класс `Approval` и функции работы с согласованиями.

### `models/decisions.py`

Содержит класс `Decision` и функции работы с решениями.

### `storage.py`

Отвечает за загрузку и сохранение данных.

Выполняет преобразования:

* JSON → объекты Python;
* объекты Python → JSON.

### `utils.py`

Содержит вспомогательные функции:

* `input_int()` – безопасный ввод целого числа.

### `tests/`

Содержит автоматизированные тесты проекта.
