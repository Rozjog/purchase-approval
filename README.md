# Сервис согласования закупок

## Назначение
Приложение предназначено для автоматизации процесса внутреннего согласования закупочных запросов в компании. Оно позволяет сотрудникам подавать заявки на покупку товаров или услуг, а руководителям и финансовому отделу — рассматривать их, утверждать или отклонять, отслеживая статус каждой заявки в реальном времени.

## Целевая аудитория
- Рядовые сотрудники — создают заявки на закупку необходимых материалов/услуг.
- Руководители отделов — проверяют обоснованность заявок и утверждают их бюджет.
- Финансовый директор — управляет бюджетом.

## Предметная область
Корпоративные закупки. В процессе закупки участвуют заявитель и его руководитель. Заявка имеет набор атрибутов: название, сумма, контрагент, статья бюджета и жизненный цикл статусов: новая -> проверка -> Согласована / Отклонена → Оплачена.

## Основные сущности
- Заявка: содержит информацию о закупаемом товаре/услуге, сумму, контрагента, сроки и текущий статус согласования.
- Пользователь: содержит данные о сотруднике, его отделе и роли (обычный сотрудник, руководитель).
- Статус: справочник статусов (На согласовании, Утверждено, Отказано, Исполнено).
- Статья затрат: справочник бюджетных статей для учета расходов.

## Основные функции
- Создание заявки: пользователь заполняет форму заявки и отправляет её на согласование.
- Одобрение заявки: заявка одобряется в зависимости от требуемого бюджета и роли.
- Контроль бюджета: при утверждении проверяется, что сумма заявки не превышает остаток бюджета отдела.
