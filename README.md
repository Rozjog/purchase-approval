# Система согласования закупок

Консольное приложение на Python для создания и согласования заявок на закупку.

Проект разработан в рамках практической работы № 2.

## Возможности

- создание заявки на закупку;
- поиск заявки по названию;
- просмотр списка заявок;
- отмена заявки;
- проверка бюджета;
- проверка прав пользователя на согласование;
- согласование заявки;
- сохранение заявок в JSON-файл;
- загрузка заявок при запуске программы;
- обработка некорректного пользовательского ввода;
- автоматическое тестирование основных функций.

### Назначение файлов

- `main.py` — запуск программы и основное меню;
- `requests.py` — функции для работы с заявками;
- `approvals.py` — проверка бюджета и согласование заявок;
- `storage.py` — загрузка и сохранение данных в JSON;
- `utils.py` — вспомогательные функции и безопасный ввод;
- `data/requests.json` — данные заявок;
- `tests/test_request.py` — автоматические тесты;
- `.flake8` — настройки проверки кода;
- `.gitignore` — файлы и каталоги, которые не добавляются в Git.

## Требования

- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Запуск программы

Из корня проекта:

```bash
python main.py
```

## Тестирование

В проекте реализованы автоматические тесты с использованием `pytest`.

Запуск тестов:

```bash
python -m pytest -v
```

## Проверка качества кода

Код проверяется линтером `flake8`.

Запуск проверки:

```bash
flake8
```
